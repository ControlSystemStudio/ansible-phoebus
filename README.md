# ansible-phoebus

Ansible collection published as `org.phoebus`.

## Scope

- Core dependencies for Phoebus
- Phoebus build and tooling roles
- Phoebus runtime service roles

## Collection name

- Namespace: `org`
- Name: `phoebus`
- Fully qualified collection name: `org.phoebus`

## Local build

```bash
ansible-galaxy collection build
```

## Initial role domains

- `phoebus_dependencies`
- `phoebus_tools`
- `phoebus_service_alarm`
- `phoebus_service_olog`
